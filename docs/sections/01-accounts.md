# Section 1 — Accounts and Workspace

<PrepImage asset="section-01" eager />

Prepare the two accounts you will use throughout the workshop.

## 1. ChatGPT desktop with Codex

1. Install the current ChatGPT desktop app for your operating system: [Windows setup](https://learn.chatgpt.com/docs/windows/windows-app) or [macOS setup](https://learn.chatgpt.com/docs/app).
2. Sign in and confirm your account can use **Codex**. Check access and usage allowance with the organizer before training.
3. Open an empty local folder as a project. Ask Codex to create a small test file using this prompt:

   ```text
   Create a file named hello.txt in this project containing "Workshop setup check". Do not change any other files.
   ```

4. Open File Explorer or Finder and confirm the file exists in that folder.

::: tip Completion check
Codex can work with a real local project folder and create a file on your laptop.
:::

## 2. GitHub account

1. [Create a GitHub account](https://github.com/signup) or sign in to your approved existing account.
2. Complete email verification and any required sign-in security steps.
3. Confirm that your account or organization allows private repositories, Pull Requests, and GitHub Actions. Resolve policy restrictions with IT before training.

::: tip Completion check
You can sign in to GitHub and have permission to use the workshop features. A GitHub account does not automatically provide ChatGPT/Codex access.
:::
